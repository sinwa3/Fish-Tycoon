# Fish Tycoon

낮에는 초밥집을 운영하고, 밤에는 남의 집에 몰래 들어가 생선을 구해오는 게임입니다.
**7일 안에 목표 금액 100,000원**을 모으는 것이 목표입니다.

> 📌 이 문서는 **1차 빌드(프로토타입)** 기준입니다. 이후 버전에서 달라질 수 있습니다.

---

## 🎮 하루 흐름

```
타이틀 → 로딩 → [낮] 영업 전 → 영업 중 → 영업 후(정산) → 로딩 → [밤] 잠입 → 다음 날 영업 전 …
```

---

## 1. 타이틀 화면

| 메뉴 | 설명 |
| --- | --- |
| **처음하기** | 1일 차부터 새로 시작합니다. 저장된 데이터가 있으면 덮어쓸지 확인 창이 뜹니다. |
| **이어하기** | 마지막으로 저장된 지점부터 이어서 합니다. |
| **옵션** | 아직 구현되지 않았습니다. |
| **종료** | 게임을 종료합니다. |

처음하기 또는 이어하기를 누르면 로딩 화면이 나옵니다.
**"계속하려면 화면을 클릭해주세요."** 문구가 나오면 화면을 클릭해 진행합니다.

---

## 2. 낮 – 초밥집 타이쿤

### 2-1. 영업 전 (메뉴 준비)
- 오른쪽 **생선 리스트**에서 지금 가진 생선과 수량을 확인합니다.
- 왼쪽 **음식 리스트**에서 가진 생선으로 만들 수 있는 초밥을 고르고, `◀ ▶`로 오늘 만들 수량을 정합니다.
  - 생선이 없어서 만들 수 없는 초밥은 어둡게 표시됩니다.
  - 초밥을 고르지 않으면 기본 메뉴인 **김초밥**만 팝니다.
- 다 정했으면 우측 하단의 **[영업 시작]** 버튼을 누릅니다.

### 2-2. 영업 중 (요리 & 서빙)
- 손님이 들어와 자리에 앉고, 말풍선으로 원하는 초밥을 주문합니다.
- 카운터 아래에 **커맨드**(W / A / S / D 조합)가 나타납니다.
  - 표시된 순서대로 키를 입력하면 초밥이 완성되어 손님에게 서빙됩니다.
- 손님 머리 위 **초록색 게이지**는 기다리는 시간입니다. 오래 기다릴수록 **만족도**가 떨어집니다.
  - 늦게 서빙해도 **판매금은 100% 다 받습니다.**
- 우측 하단 **진행도** 바가 모두 차면 영업이 끝납니다.

### 2-3. 영업 후 (정산)
영업이 끝나면 휴대폰 모양의 **정산 창**이 뜹니다.

| 항목 | 설명 |
| --- | --- |
| 기본 소지금 | 영업 전에 가지고 있던 돈 |
| 음식 판매금 | 오늘 판 초밥의 총액 |
| 평판 보너스 | 음식 판매금 × 평판 배율 |
| 남은 생선 자동 매각 | 오늘 쓰지 않은 생선은 **자동으로 팔립니다** |
| **합계** | 오늘 정산 후 소지금 |

- 정산이 끝나면 게임이 **자동 저장**됩니다.
- **[닫기]**로 창을 닫은 뒤, 화면 우측 하단의 **흰색 화살표**를 누르면 밤 잠입 파트로 넘어갑니다.

---

## 3. 밤 – 3D 잠입 (1인칭)

> ⚠️ 1차 빌드에서는 **플레이어 이동만** 구현되어 있습니다. 생선 훔치기는 임시 기능으로 대신합니다.

- 첫 번째 **E**: 생선 한 종류를 무작위로 골라 무작위 수량만큼 지급합니다 (임시).
  - 이때 다음 날로 넘어가고 게임이 **자동 저장**됩니다.
- 두 번째 **E**: 다음 날 **낮 영업 전** 화면으로 돌아갑니다.

---

## ⌨️ 조작법

### 낮 (타이쿤)
| 키 | 동작 |
| --- | --- |
| 마우스 좌클릭 | 메뉴 선택, 수량 조절, 버튼 클릭 |
| W / A / S / D | 화면에 나온 요리 커맨드 입력 |
| Esc | 일시정지 |

### 밤 (잠입)
| 키 | 동작 |
| --- | --- |
| W / A / S / D | 이동 |
| 마우스 | 시점 회전 |
| Left Shift (누르는 동안) | 달리기 (스태미나 소모) |
| Left Ctrl (토글) | 웅크리기 |
| E | 다음 페이즈 (임시) |
| Esc | 일시정지 |

---

## 🏁 엔딩
- **7일 차** 영업이 끝난 뒤 정산에서 결과가 결정됩니다.
  - 소지금이 **100,000원 이상**이면 성공, 부족하면 실패입니다.
- 엔딩 화면에서 타이틀로 돌아가면 저장 데이터가 삭제됩니다.

---

## 💾 저장 & 이어하기
- 자동 저장 시점은 두 번입니다.
  - **낮 정산이 끝났을 때**
  - **밤 잠입에서 생선을 받았을 때**
- 이어하기를 누르면 마지막 저장 지점에 따라 다음 화면부터 시작합니다.
  - 낮 정산 후에 저장했다면 → 정산이 끝난 낮 화면 (화살표를 눌러 밤으로 이동)
  - 밤 잠입 후에 저장했다면 → 다음 날 영업 전 화면
